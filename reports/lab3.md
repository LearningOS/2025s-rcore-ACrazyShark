## 编程作业
### spawn 系统调用
内核首先验证可执行文件路径及参数的合法性，随后为新进程分配独立的地址空间与进程控制块（PCB），解析目标程序的ELF格式并加载代码段、数据段至内存，初始化用户态栈空间并压入参数与环境变量，建立与父进程的资源继承关系，完成上下文切换所需的寄存器状态配置，最后将新进程加入调度队列使其就绪。

### stride 调度算法
Stride调度算法为每个任务分配与其优先级成反比的步长增量（Pass = BIG_STRIDE/优先级），并始终选择当前累计步长（stride）最小的任务执行，执行后为该任务增加其步长增量，通过数学反比关系保障高优先级任务获得更多调度机会。

        let a = self.0;
        let b = other.0;
        let diff = a.wrapping_sub(b);
        if diff > BIG_STRIDE / 2 {
            Some(Ordering::Greater)
        } else if diff < (BIG_STRIDE / 2).wrapping_neg() {
